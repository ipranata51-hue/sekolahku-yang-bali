# Dokumentasi Inovasi

Folder ini digunakan untuk menyimpan foto, video, dan catatan aktivitas inovasi Program Sekolahku yang BALI.

## Cara menambahkan dokumentasi
1. Klik **Add file → Upload files**.
2. Unggah foto/video kegiatan atau produk inovasi.
3. Untuk uraian kegiatan, unggah file `.txt` atau `.md`.
4. Commit perubahan ke branch `main`.

Website akan membaca isi folder ini secara otomatis.
