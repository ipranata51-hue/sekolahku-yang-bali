📋 Cara mengunggah

  1. Pilih tim yang sesuai.
  2. Pastikan sudah login ke akun GitHub yang memiliki akses tulis ke repository.
  3. Pilih Add file → Upload files.
  4. Pilih beberapa foto sekaligus.
  5. Untuk uraian aktivitas, tambahkan file .md atau .txt.
  6. Klik Commit changes.
  7. Tunggu deploy website. Dokumentasi akan terbaca otomatis oleh modul BALI Rangers.
